Projet d'automatisation des tests utilisant **Robot Framework** et les **Design Patterns**,
couvrant les tests UI avec SeleniumLibrary et les tests API avec RequestsLibrary.
---

##  Technologies utilisées

| Technologie | Usage |
|-------------|-------|
| Robot Framework | Framework de test |
| SeleniumLibrary | Automatisation UI |
| RequestsLibrary | Tests API REST |
| SauceLabs | Exécution cloud |
| Python | Langage de base |

---

##  Contenu des modules

###  SauceLabsProject
- Login valide / invalide
- Ajout au panier
- Checkout complet
- Design Pattern : Page Object Model

###  Test_Api
- Création d'un animal (POST)
- Récupération (GET)
- Mise à jour (PUT)
- Suppression (DELETE)
- Authentification Basic Auth

---

##  Prérequis

```bash
pip install robotframework
pip install robotframework-seleniumlibrary
pip install robotframework-requests
```
